## 🚀 About The Project

**InstaClone** is a full-stack social media web application inspired by Instagram - built from scratch with persistence, frustration, debugging sessions, and way too many console logs.

This project represents more than features.
It represents learning the hard way.

Every authentication bug, every UI glitch, every backend crash - fixed manually.
No shortcuts. No templates. Just effort.

---

* 🔐 User Authentication (Sign up / Login)

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Dileep-kumawat/Insta-clone.git
cd Insta-clone
```

Install dependencies for backend:

```bash
cd backend
npm install
```

Install dependencies for frontend:

```bash
cd frontend
npm install
```

Run backend:

```bash
npm start
```

Run frontend:

```bash
npm start
```
